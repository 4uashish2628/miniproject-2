# Submission checklist

The supplied institute guidelines refer to Table I and a common project template, but neither was supplied. Do not invent the dates or claim template compliance until you obtain them.

- Confirm the title and scope with the faculty supervisor and complete project registration.
- Form the normally required three-student group. Seek the Head of Department's permission if using a smaller group.
- Add actual names, roll numbers, department and supervisor to the report and slides.
- Obtain Table I and the institute's common project report template. Adapt the editable report accordingly.
- Complete the consented recordings, real training and held-out participant evaluation.
- Add actual dataset counts, confusion matrix, metrics, screenshots and limitations to the report. Keep source citations and distinguish reused software from project contributions.
- Evaluate repetition counts and smoothing separately, if making claims about them.
- Run the demo on the presentation laptop, check full-body framing, and keep an agreed local backup video.
- Replace all pending-results and identity placeholders. Do not add a signature or approval that has not been provided.
- Rehearse the viva. Each member should explain their actual contribution and the full workflow.
- Submit the report soft copy to the assessment committee at least **three working days before each presentation**, as stated in the guidelines.
- Bring administrative questions to the project coordinator. Committee composition and grading follow the institute's guidelines.
